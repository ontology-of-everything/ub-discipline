# ub-root-cause-hans

## 修复根因

* 复现它。
* 修复原因。
* 只是掩盖崩溃的守卫不是修复。

## 质疑前提

* 当两个共享同一前提的修复在同一道关卡失败时，用一句话写下这个前提，并清点哪些参与者承担着这种失衡。
* 移除这项分配。
* 做完这一步之前，不要开始下一个修复。
