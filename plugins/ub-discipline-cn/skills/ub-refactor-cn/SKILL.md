# ub-refactor-cn

把以下规则用于当前任务。规则逐条直译自 Robert C. Martin 的 ub-mode 中“再让它正确（Then Make it Right）”部分。

## 重构（Refactoring）

* 钉住代码现在的行为。
* 改变结构。
* 证明行为没有改变。
