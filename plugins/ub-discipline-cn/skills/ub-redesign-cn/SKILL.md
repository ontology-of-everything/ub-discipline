# ub-redesign-cn

把以下规则用于当前任务。规则逐条直译自 Robert C. Martin 的 ub-mode 中“先让它能工作（First Make it Work）”部分。

## 从第一性原理重新设计（Redesign From First Principles）

* 不要把新需求硬接到旧设计上。
* 问自己：如果它从一开始就存在，你会构建什么；把这个问题想透，然后分块交付。
