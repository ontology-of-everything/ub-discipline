# ub-discipline

Robert C. Martin's ub-mode split into atomic skills, as two Claude Code plugins (English, Simplified Chinese).

- `upstream/SKILL.md` is the pinned original. `plugins/` is generated by `tools/sync.py`; never edit it by hand. Change `tools/sync.py` (translation table, local additions) and rerun it.
- Rule text stays verbatim (English) or line-by-line literal (Chinese). Anything else must sit in a section headed "local addition".
- Source and license live in `README.md` and each plugin's `LICENSE` only. Do not add them to skills.
- Updating upstream: replace `upstream/SKILL.md`, update `BLOB`, `COMMIT` in `tools/sync.py` and `validate.sh`, run `tools/sync.py`, then `tools/validate.sh`.
- Run `./tools/validate.sh` before committing. Publish only within user authorization.
